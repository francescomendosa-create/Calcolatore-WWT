- App (installabile): `https://francescomendosa-create.github.io/Calcolatore-WWT/`

## Installa sul PC

1. Apri il link sopra con **Edge** o **Chrome**
2. Tocca **Installa PC** in alto (oppure ⋯ → App → Installa questa app)
3. Se non compare: scarica / esegui `Installa-Process-Managed-PC.bat` (apre una finestra app senza barra del browser)

## GitHub Desktop

1. File → Add local repository → `C:\Users\franc\Documents\GitHub\Calcolatore-WWT`
2. Publish repository (nome: `Calcolatore-WWT`)
3. Settings → Pages → Deploy from branch `main` / root
